# ⚡ AI Code Explainer

An IDE-style AI-powered tool to explain, debug, and optimize code in multiple languages.

## 🚀 Live Demo
[Daksh2006jain.github.io/code-explainer](https://Dakshjain2006.github.io/code-explainer)

## ✨ Features
- **3 Modes:** Explain · Debug · Optimize
- Supports Python, C++, JavaScript, Java, SQL, Bash, HTML/CSS
- Auto language detection
- **Explain Mode:** Step-by-step walkthrough, time/space complexity, concept tags
- **Debug Mode:** Bug detection, fixes, corrected code snippets, best practices
- **Optimize Mode:** Complexity comparison, bottlenecks, improved code
- Built-in snippet library (Binary Search, Fibonacci, Bubble Sort, Linked List)
- GitHub-inspired dark UI
